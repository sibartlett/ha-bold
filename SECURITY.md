# Security

Please report security problems privately, not in a public issue: use
**Report a vulnerability** on this repository's
[Security tab](https://github.com/sibartlett/ha-bold/security). I'll reply
there, and publish a fix and an advisory once it's resolved.

Security fixes go into the latest version.

This integration can unlock doors, so reports about anything that could let
someone unlock a lock, or read the Bluetooth keys, Bold sign-in or webhook
secret it stores, are especially welcome.
